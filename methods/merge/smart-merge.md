# Έξυπνη Συγχώνευση (Παράλληλοι Δείκτες)

> **Σημείωση:** Εφαρμόζεται όταν οι πίνακες Α και Β είναι **ήδη ταξινομημένοι**.

```
ΑΡΧΗ
  i <- 1
  j <- 1
  k <- 1
  
  ΟΣΟ (i <= 25) ΚΑΙ (j <= 21) ΕΠΑΝΑΛΑΒΕ
    ΑΝ Α[i] < Β[j] ΤΟΤΕ
      Γ[k] <- Α[i]
      i <- i + 1
    ΑΛΛΙΩΣ
      Γ[k] <- Β[j]
      j <- j + 1
    ΤΕΛΟΣ_ΑΝ
    k <- k + 1
  ΤΕΛΟΣ_ΕΠΑΝΑΛΗΨΗΣ
  
  ΑΝ i > 25 ΤΟΤΕ
    ΓΙΑ λ ΑΠΟ j ΜΕΧΡΙ 21
      Γ[k] <- Β[λ]
      k <- k + 1
    ΤΕΛΟΣ_ΕΠΑΝΑΛΗΨΗΣ
  ΑΛΛΙΩΣ
    ΓΙΑ λ ΑΠΟ i ΜΕΧΡΙ 25
      Γ[k] <- Α[λ]
      k <- k + 1
    ΤΕΛΟΣ_ΕΠΑΝΑΛΗΨΗΣ
  ΤΕΛΟΣ_ΑΝ
