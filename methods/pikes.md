# ΤΕΤΡΑΓΩΝΙΚΟΙ ΠΙΝΑΚΕΣ
- ΚΥΡΙΑ ΔΙΑΓΩΝΙΟΣ: i=j
- ΔΕΥΤΕΡΕΥΟΥΣΑ ΔΙΑΓΩΝΙΟΣ - ΓΕΝΙΚΑ (ΝΧΝ): i+j=N+1
- ΠΑΝΩ ΑΠΟ ΤΗΝ ΚΥΡΙΑ ΔΙΑΓΩΝΙΟ: i<j
- ΚΑΤΩ ΑΠΟ ΤΗΝ ΚΥΡΙΑ ΔΙΑΓΩΝΙΟ: i>j
- ΕΝΑΛΛΑΞ (ΣΚΑΚΙΕΡΑ): (i+j) MOD 2 = 0 / (i+j) MOD 2 = 1
