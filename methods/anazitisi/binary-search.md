# Δυαδική Αναζήτηση (Σε Γλώσσα Πανελλαδικών)

> **Σημείωση:** Η Δυαδική Αναζήτηση εφαρμόζεται **ΜΟΝΟ** σε ταξινομημένους πίνακες.

```algol
ΠΡΟΓΡΑΜΜΑ Δυαδικη_Αναζητηση
ΜΕΤΑΒΛΗΤΕΣ
  ΑΚΕΡΑΙΕΣ: πίνακας[100], αρχή, τέλος, μέση, στοιχείο, n, i
  ΛΟΓΙΚΕΣ: βρέθηκε
ΑΡΧΗ
  ΔΙΑΒΑΣΕ n
  ΓΙΑ i ΑΠΟ 1 ΜΕΧΡΙ n
    ΔΙΑΒΑΣΕ πίνακας[i]
  ΤΕΛΟΣ_ΓΙΑ
  
  ΔΙΑΒΑΣΕ στοιχείο
  
  αρχή <- 1
  τέλος <- n
  βρέθηκε <- ΨΕΥΔΗΣ
  
  ΟΣΟ (αρχή <= τέλος) ΚΑΙ (βρέθηκε = ΨΕΥΔΗΣ) ΕΠΑΝΑΛΑΒΕ
    μέση <- (αρχή + τέλος) DIV 2
    
    ΑΝ πίνακας[μέση] = στοιχείο ΤΟΤΕ
      βρέθηκε <- ΑΛΗΘΗΣ
    ΑΛΛΙΩΣ_ΑΝ πίνακας[μέση] < στοιχείο ΤΟΤΕ
      αρχή <- μέση + 1
    ΑΛΛΙΩΣ
      τέλος <- μέση - 1
    ΤΕΛΟΣ_ΑΝ
  ΤΕΛΟΣ_ΟΣΟ
  
  ΑΝ βρέθηκε = ΑΛΗΘΗΣ ΤΟΤΕ
    ΓΡΑΨΕ "Το στοιχείο βρέθηκε στη θέση: ", μέση
  ΑΛΛΙΩΣ
    ΓΡΑΨΕ "Το στοιχείο δεν βρέθηκε στον πίνακα."
  ΤΕΛΟΣ_ΑΝ
ΤΕΛΟΣ_ΠΡΟΓΡΑΜΜΑΤΟΣ
