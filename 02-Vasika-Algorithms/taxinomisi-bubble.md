#Ταξινόμηση Φυσαλίδας (Bubble Sort)

> Η ταξινόμηση φυσαλίδας συγκρίνει συνεχώς τα διπλανά στοιχεία και τα εναλλάσσει αν είναι λάθος σειρά.

---

## Αύξουσα Ταξινόμηση (από το μικρότερο στο μεγαλύτερο)
Χρησιμοποιούμε σύμβολο **`>`**:

```
ΓΙΑ i ΑΠΟ 2 ΜΕΧΡΙ Ν
    ΓΙΑ j ΑΠΟ Ν ΜΕΧΡΙ i ΜΕ_ΒΗΜΑ -1
        ΑΝ A[j-1] > A[j] ΤΟΤΕ
            temp ← A[j-1]
            A[j-1] ← A[j]
            A[j] ← temp
        ΤΕΛΟΣ_ΑΝ
    ΤΕΛΟΣ_ΕΠΑΝΑΛΗΨΗΣ
ΤΕΛΟΣ_ΕΠΑΝΑΛΗΨΗΣ
```

## Φθίνουσα Ταξινόμηση (από το μεγαλύτερο στο μικρότερο)
Χρησιμοποιούμε σύμβολο **`<`**:

```
ΓΙΑ i ΑΠΟ 2 ΜΕΧΡΙ Ν
    ΓΙΑ j ΑΠΟ Ν ΜΕΧΡΙ i ΜΕ -1
        ΑΝ A[j-1] < A[j] ΤΟΤΕ
            temp ← A[j-1]
            A[j-1] ← A[j]
            A[j] ← temp
        ΤΕΛΟΣ_ΑΝ
    ΤΕΛΟΣ_ΕΠΑΝΑΛΗΨΗΣ
ΤΕΛΟΣ_ΕΠΑΝΑΛΗΨΗΣ
